## Data model for rich previews
- Verse id = `book.chapter.verse` (e.g. `jehovih.1.3`). Chapter JSON: content/books/<book>/chapter-NN.json
  has `{id, book, chapter, title, preamble, verses:[{id, verse_number, en, zh_hant, zh_hans, ja,
  glossary_terms, images}]}`. Book titles in content/meta/books.json (`{slug,title,chapter_count}`).
- Chapter page route: `/oahspe/<book>/<book.chapter>` (localized: `/oahspe/<locale>/<book>/<book.chapter>`),
  verse anchor `#<verse id>`. Verse DOM: `<div id="{verse.id}" class="verse-row">` in VerseReader.
- MDX generated by `scripts/json-to-mdx.py`; site pages render via VerseReader component.
