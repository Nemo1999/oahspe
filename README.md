# Oahspe Digital Edition

A modern Docusaurus v3 site presenting Oahspe (1882) — all 34 books, 97 illustrated plates, and a searchable glossary — hosted at **https://nemo1999.github.io/oahspe**.

## Quick Start

```bash
# 1. Clone
git clone https://github.com/Nemo1999/oahspe.git
cd oahspe

# 2. Install Node dependencies (site only)
npm install

# 3. Scrape source content from sacred-texts.com
npm run scrape

# 4. Build the Docusaurus site
npm run build

# 5. Preview locally
npm run serve
```

Python scripts require Python 3.10+ with dependencies from `requirements.txt`:

```bash
pip install -r requirements.txt
```

## Project Layout

```
oahspe/
├── content/
│   ├── books/          # Per-book MDX files (generated by scrape)
│   ├── glossary/       # terms.json — glossary entries
│   └── meta/
│       ├── books.json  # Book manifest (slug, title, chapter_count)
│       └── plates.json # Plate manifest (id, title, filenames)
├── scripts/
│   ├── scrape-sacred-texts.py   # Fetch & parse all 34 books
│   ├── extract-plates.py        # Download and thumbnail plate images
│   ├── translate.py             # AI-assisted translation pass
│   ├── build-glossary.py        # Build glossary from scraped terms
│   └── validate.py              # Validate JSON manifests and MDX
├── site/               # Docusaurus v3 project
│   ├── src/            # React components and pages
│   ├── static/         # Static assets (plates, icons)
│   └── docusaurus.config.ts
├── .github/
│   └── workflows/
│       └── deploy.yml  # GitHub Pages deploy
└── requirements.txt
```

## Scripts

| Command | Description |
|---|---|
| `npm run scrape` | Scrape all book text from sacred-texts.com into `content/books/` |
| `npm run plates` | Download plate images and generate thumbnails |
| `npm run translate` | AI translation pass (requires `OPENAI_API_KEY`) |
| `npm run glossary` | Rebuild `content/glossary/terms.json` from scraped content |
| `npm run validate` | Validate all JSON manifests and MDX files |
| `npm run build` | Build Docusaurus site to `site/build/` |
| `npm run start` | Start Docusaurus dev server |
| `npm run serve` | Serve the production build locally |
